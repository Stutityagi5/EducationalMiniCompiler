# Educational Mini Compiler

A web-based educational mini compiler designed to demonstrate the major phases of compilation for C-like source code through an interactive and easy-to-understand interface.

The application analyzes source code and displays tokens, errors, warnings, corrected code, an Abstract Syntax Tree (AST), and a symbol table.

## Features

- Preprocessing of C-like source code
- Lexical analysis and token generation
- Syntax error detection
- Semantic error detection
- Logical error and warning detection
- Corrected code generation
- Token visualization
- Abstract Syntax Tree (AST) visualization
- Symbol table generation
- Interactive web-based interface

## How It Works

The compiler processes the entered source code through multiple stages:

1. **Preprocessing** – Prepares the source code for further analysis.
2. **Lexical Analysis** – Converts the source code into tokens.
3. **Syntax Analysis** – Checks the syntactic structure of the program.
4. **Semantic Analysis** – Performs semantic checks on the code.
5. **Logical Error Detection** – Identifies possible logical issues and warnings.
6. **Code Correction** – Generates corrected code where possible.
7. **AST Generation** – Creates an Abstract Syntax Tree representing the program structure.
8. **Symbol Table Generation** – Stores information about identifiers used in the program.

The results of these stages are displayed through the web interface.

## Purpose

The main purpose of this project is to provide an interactive way to understand compiler design concepts.

Instead of studying compiler phases only theoretically, users can enter C-like source code and observe how it is processed through different stages of compilation.
